# Add-on terminology

Use these terms in the add-on interface and its documentation.
Use the same term for the same item.
Use ASD-STE100 Issue 9 for English sentence structure and general words.
The terms in this document apply to computer processes and applications.

| Technical noun | Meaning |
| --- | --- |
| add-on | A package that adds a declared function to Hakone. |
| contribution | One function that an add-on declares. |
| provider | A contribution that supplies metadata or finds media. |
| theme | Data that sets the permitted colors, shapes, and effects of the interface. |
| metadata | Data that describes media. |
| credential | Secret data that permits access to an account or a service. |
| API key | A credential that an API uses. |
| session | The current operation period. Session data does not continue after the app stops. |
| play queue | The ordered media items that Hakone can play. |
| schema | Data that specifies permitted fields, types, and limits. |
| binding | A reference to a field in a declared state object. |
| UI hook | An interface location that permits a declared contribution. |
| Git repository | A collection of files and their Git history. |
| release tag | A Git name that identifies a release. |
| package digest | A content identifier that the host calculates for a package. |
| settings snapshot | A copy of settings for a specified package version. |
| token | A named value that the interface uses. |
| focus indicator | The visible mark for a control that has keyboard focus. |
| high contrast | A color mode that increases the contrast between text and its background. |
| screen reader | Software that reads interface information to a user. |

| Technical verb | Use in this project |
| --- | --- |
| configure | Set the options that an add-on needs. |
| enable / disable | Permit or stop the functions of an installed add-on. |
| install | Put an add-on package in the managed package store. |
| load | Read data into an app component. |
| save | Write data to the applicable settings store. |
| store | Keep data in a data store. |
| validate | Do a check of data against its declared rules. |
| recover | Select a saved add-on package that passes validation. Keep the add-on disabled. |
| restore | Install an app package again from its registered app distribution. |
| highlight | Change the visual state of an interface item to identify it. |

Keep API identifiers, protocol values, and product names unchanged.
Use these identifiers as technical names, not as alternatives for general words.
